# 🏀 NBA Style Clash: Opening Night Radar

A Python-based interactive data visualization comparing the offensive styles of the Philadelphia 76ers and New York Knicks from their opening night matchup on Oct 20, 2026.

## Tech Stack
* **Language:** Python 3.10+
* **Data Processing:** Pandas, nba_api
* **Visualization:** Plotly (Radar Charts)
* **Frontend/Deployment:** Streamlit

## The Insight
Visualizing how the 76ers overcame a massive rebounding deficit (45-53) through elite perimeter scoring and ball security.

## How to Run Locally
1. Clone the repo
2. `pip install -r requirements.txt`
3. `streamlit run app.py`
